# Vildersoft Admin

Vildersoft Admin is a private, internal administration tool. It is used by a single company for its own paperwork. It is not offered to the public and has no other users.

Contact: vildersoft@gmail.com

## Privacy Policy

Last updated: 5 October 2026

### Who this applies to

The tool has one user, its owner, who signs in with the company's own Google account. Nobody else can sign in or use it.

### What data the tool accesses

With the owner's consent, the tool accesses the owner's own Google account data (mail, files and documents) in order to organise the company's own administrative records.

### How the data is used

The data is used only for the company's internal administration. It is not used for advertising or profiling, and it is not sold.

### Where the data is stored

The data stays on the owner's own equipment and in the owner's own Google account.

### Sharing

The data is not shared with third parties, except with service providers that the owner uses for the company's administration and record keeping, and only as far as that work requires.

### Google API Services User Data Policy

The tool's use and transfer of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

### Retention and deletion

Data is kept only as long as the company's record keeping requires. The owner can delete it at any time and can remove the tool's access at any time in the Google account settings.

### Changes

Changes to this policy are published on this page.

## Terms of Service

Vildersoft Admin is for internal use only and is provided without any warranty. It is not available to other persons or organisations.
